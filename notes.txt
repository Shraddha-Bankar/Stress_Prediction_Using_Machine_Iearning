Stress Prediction Using Machine Learning

─────────────────────────────────────────────
1. PREREQUISITES
─────────────────────────────────────────────
Make sure the following are installed on your system:

  - Python 3.8+          → https://www.python.org/downloads/
  - pip (Python package manager)
  - Git                  → https://git-scm.com/
  - Node.js (optional)   → Only needed if frontend build tools are used
  - Vercel CLI (optional)→ For deployment: npm install -g vercel


─────────────────────────────────────────────
2. CLONE THE REPOSITORY
─────────────────────────────────────────────

  git clone https://github.com/Shraddha-Bankar/Stress_Prediction_Using_Machine_Iearning.git
  cd Stress_Prediction_Using_Machine_Iearning


─────────────────────────────────────────────
3. VIRTUAL ENVIRONMENT SETUP (Recommended)
─────────────────────────────────────────────

  # Create virtual environment
  python -m venv venv

  # Activate (Windows)
  venv\Scripts\activate

  # Activate (macOS/Linux)
  source venv/bin/activate

  # Deactivate when done
  deactivate


─────────────────────────────────────────────
4. INSTALL DEPENDENCIES
─────────────────────────────────────────────

  pip install -r requirements.txt

  Common packages in requirements.txt:
    - flask
    - scikit-learn
    - pandas
    - numpy
    - joblib
    - gunicorn          (for production)
    - python-dotenv     (for .env support)


─────────────────────────────────────────────
5. ENVIRONMENT VARIABLES (.env file)
─────────────────────────────────────────────

  Create a .env file in the root directory:

    SECRET_KEY=your_secret_key_here
    DATABASE_URL=your_database_url_here
    DEBUG=True

  Load in app.py:
    from dotenv import load_dotenv
    load_dotenv()


─────────────────────────────────────────────
6. DATABASE SETUP & MIGRATION
─────────────────────────────────────────────

  # Initialize / migrate the database
  python migrate.py

  # Test database connectivity
  python test_db.py


─────────────────────────────────────────────
7. TRAIN THE MACHINE LEARNING MODEL
─────────────────────────────────────────────

  # Run model training (saves model to /models/ directory)
  python model.py

  This script:
    - Loads and preprocesses the dataset
    - Trains ML classifier (e.g., Random Forest / SVM / Decision Tree)
    - Evaluates with accuracy, precision, recall, F1-score
    - Saves the trained model as models/stress_model.pkl


─────────────────────────────────────────────
8. RUN THE FLASK APP (Development)
─────────────────────────────────────────────

  python app.py

  OR with Flask CLI:

  set FLASK_APP=app.py          (Windows)
  export FLASK_APP=app.py       (macOS/Linux)
  flask run

  App runs at → http://127.0.0.1:5000/


─────────────────────────────────────────────
9. RUN IN PRODUCTION MODE (Gunicorn)
─────────────────────────────────────────────

  gunicorn -w 4 app:app

  Flags:
    -w 4        → 4 worker processes
    app:app     → module:Flask-instance


─────────────────────────────────────────────
10. PROJECT ROUTES (Flask Endpoints)
─────────────────────────────────────────────

  GET  /              → Home / Landing page (index.html)
  GET  /predict       → Prediction input form (predict.html)
  POST /predict       → Submits form data, runs model, returns prediction
  GET  /result        → Displays stress prediction result (result.html)


─────────────────────────────────────────────
11. DEPLOY TO VERCEL
─────────────────────────────────────────────

  Step 1: Install Vercel CLI
    npm install -g vercel

  Step 2: Login
    vercel login

  Step 3: Deploy
    vercel

  Step 4: Production deploy
    vercel --prod

  vercel.json configuration example:
  ─────────────────────────────────
  {
    "version": 2,
    "builds": [
      { "src": "app.py", "use": "@vercel/python" }
    ],
    "routes": [
      { "src": "/(.*)", "dest": "app.py" }
    ]
  }
  ─────────────────────────────────

  Live URL: https://<your-project>.vercel.app

14. COMMON ERRORS & FIXES
─────────────────────────────────────────────

  ERROR: ModuleNotFoundError
  FIX:   pip install -r requirements.txt

  ERROR: Model file not found
  FIX:   Run python model.py to generate /models/stress_model.pkl

  ERROR: Port 5000 already in use
  FIX:   flask run --port 5001
         OR kill existing process on port 5000

  ERROR: Database connection failed
  FIX:   Check .env DATABASE_URL and run python migrate.py

  ERROR: Vercel build fails
  FIX:   Ensure vercel.json points to correct entry: "src": "app.py"
         Ensure requirements.txt is present in root directory
