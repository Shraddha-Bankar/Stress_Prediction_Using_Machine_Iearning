File Descriptions
================================================

app.py
  - Main Flask web application
  - Defines routes: '/' (home), '/predict' (form), '/result' (output)
  - Loads the trained ML model from /models/
  - Handles user input, preprocessing, and returns prediction

model.py
  - Loads and preprocesses the dataset
  - Trains machine learning model(s) (e.g., Random Forest, SVM, etc.)
  - Evaluates model performance (accuracy, confusion matrix, etc.)
  - Saves trained model to /models/ directory using pickle/joblib

migrate.py
  - Handles database schema setup or migration
  - Creates tables, initializes DB for storing predictions/logs

test_db.py
  - Tests database connectivity
  - Verifies CRUD operations work correctly

requirements.txt
  - Lists all Python dependencies
  - Common packages: flask, scikit-learn, pandas, numpy, joblib, etc.

vercel.json
  - Configuration for deploying the Flask app on Vercel
  - Defines build commands, routes, and runtime settings

.gitignore
  - Excludes: __pycache__/, *.pyc, .env, venv/, *.pkl (optional), etc.
